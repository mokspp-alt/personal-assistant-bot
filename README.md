# Ассистент личных дел

Telegram-бот для своих дел: пишете или говорите голосом, как обычно, а бот записывает дела,
напоминает о них вовремя, ведёт списки покупок и хранит заметки. Утром присылает сводку дел на день.

## Что умеет

- **Дела со сроками и напоминаниями:** «напомни завтра в 9:30 позвонить маме», «в пятницу
  в 18:00 стрижка» (о встречах со временем напоминает за час), «через 20 минут вытащить бельё».
- **Повторы:** «каждый день в 21:00 таблетка», «по будням в 8:00 зарядка», «каждый месяц
  10-го платить за квартиру», «12 марта день рождения Оли» (каждый год). Если повтор не отмечен
  выполненным, на следующий день бот всё равно напомнит снова.
- **Списки:** «купить молоко, хлеб и батарейки» — три пункта в списке «покупки»; «молоко купил»
  — вычёркивает. Другие списки — по названию: «в список для отпуска: крем от солнца».
- **Изменения словами:** «перенеси стрижку на субботу», «по стрижке напомни за два часа»,
  «стрижку отменили», «что я сделал за неделю?».
- **Заметки:** «запомни: код домофона 45К1234», потом «какой у нас код домофона?».
- **Голосовые** распознаются прямо на сервере (Whisper), бот показывает, что расслышал.
- **Фото и файлы:** квитанция, письмо, билет, приглашение, PDF, Excel. Бот пересказывает главное
  и предлагает записать срок («оплатить до 10.11», «вылет 12.11 в 7:40»); если в подписи
  попросить — записывает сразу.
- **Google Календарь:** встречи, визиты, поездки, «встретить тёщу с поезда», дни рождения и всё,
  что попросите «в календарь», бот добавляет событием с оповещением (место, номер поезда, вагон —
  в описании). Перенос и удаление дела меняют и событие. Подключение — ниже.
- **Напоминание с кнопками:** «✅ Готово», «⏰ 15 мин», «⏰ 1 час», «🌅 Завтра».
- **Утренняя сводка** (по умолчанию в 8:30): дела на сегодня и то, что не сделано раньше.
  Если дел со сроком нет, бот не пишет.

Фразы разбирает Claude (по умолчанию `claude-haiku-5-5`, effort `medium`) с инструментами
(strict tools) и кэшированием промпта. Без ключа бот тоже работает, но проще: каждое
сообщение записывается делом без срока.

Бот личный: отвечает только владельцу — тому, кто первым написал ему `/start`.
Чтобы пустить кого-то ещё (или задать владельца заранее), впишите id через запятую
в `ALLOWED_USERS` в `.env`; бот подскажет id чужому человеку, когда тот напишет.

## Команды

| Команда | Что делает |
|---|---|
| `/list` | все дела: просроченные, сегодня, завтра, позже, списки без срока |
| `/today` | дела на сегодня |
| `/notes` | заметки |
| `/done 12` / `/del 12` | отметить дело #12 выполненным / удалить |
| `/digest 08:30` / `off` | время утренней сводки |
| `/tz Europe/Moscow` | часовой пояс |
| `/calendar` | Google Календарь: подсказка по подключению, проверка; `/calendar адрес@gmail.com` — выбрать календарь, `off` — отключить |

## Установка на сервер

Ubuntu 22.04+, Python 3.10+, PM2. Одной командой (спросит токен от @BotFather):

```bash
curl -L raw.githubusercontent.com/mokspp-alt/personal-assistant-bot/main/i | sh
```

Скрипт ставит бота в `/var/www/personal-assistant-bot`, запускает PM2-процесс `personal-assistant-bot` и
больше ничего на сервере не трогает: портов бот не открывает (long polling). Ключ Claude
и прокси берёт из `/var/www/empathy-bridge/.env.local` (`ANTHROPIC_API_KEY`,
`ANTHROPIC_PROXY_URL` → `ANTHROPIC_PROXY` и `TELEGRAM_PROXY`), если в `.env` они ещё пустые;
значения на экран не выводятся. Другой источник: `SECRETS_FROM=/путь/.env`.

Обновление — та же команда. Логи: `pm2 logs personal-assistant-bot`, перезапуск: `pm2 restart personal-assistant-bot`.

Голосовые распознаёт [faster-whisper](https://github.com/SYSTRAN/faster-whisper): модель
скачивается при первом запуске в `data/models`. `small` нужен ~1 ГБ памяти; если при установке
свободно меньше 2 ГБ, скрипт ставит `base` (~300 МБ). Поменять — `WHISPER_MODEL` в `.env`.

## Google Календарь

Бот пишет в календарь через служебный аккаунт Google — без входа в ваш аккаунт и без OAuth:

1. [console.cloud.google.com](https://console.cloud.google.com): создать проект → APIs & Services →
   Library → **Google Calendar API** → Enable.
2. IAM & Admin → Service Accounts → Create service account → открыть его → Keys → Add key →
   Create new key → **JSON**.
3. Прислать скачанный `.json` боту файлом. Бот сохранит ключ в `data/google-sa.json` (права 600),
   удалит сообщение и пришлёт адрес служебного аккаунта.
4. [calendar.google.com](https://calendar.google.com) → настройки своего календаря → «Открыть доступ
   пользователям» → адрес служебного аккаунта → «Внесение изменений в мероприятия».
5. Написать боту `/calendar ваш_адрес@gmail.com` — он проверит доступ.

Запросы к Google идут через `GOOGLE_PROXY`, а если он пуст — через тот же прокси, что и Claude.

## Разработка

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt pytest
.venv/bin/python -m pytest
```

- `lifebot/tools.py` — операции с делами и заметками (их вызывает Claude и кнопки), тексты списков,
  сводки и напоминаний;
- `lifebot/assistant.py` — промпт, инструменты и цикл вызова Claude;
- `lifebot/bot.py` — обработчики Telegram, доступ, ежеминутная проверка напоминаний и сводки;
- `lifebot/storage.py` — SQLite, `lifebot/dates.py` — даты и повторы,
  `lifebot/stt.py` — голос, `lifebot/attachments.py` — фото и файлы,
  `lifebot/gcal.py` — Google Календарь.

Сравнение моделей на реальных фразах (ходит в API, стоит центы):

```bash
.venv/bin/python evals/compare_models.py claude-haiku-5-5:medium claude-sonnet-5-5:low
```
