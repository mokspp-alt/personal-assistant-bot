# personal-assistant-bot — правила для Claude

- Каждое законченное изменение — сразу коммит в `main` и `git push origin main`, без веток.
  Сообщения коммитов — по-русски.
- Перед коммитом: `.venv/bin/python -m pytest` — все тесты проходят. На каждую фичу — тест.
- На сервере Python 3.10: без `datetime.UTC`, `typing.Self` и прочего из 3.11+.
- Сервер недоступен из облака: команды для сервера давать пользователю (он вставляет их
  в Termius с iPhone). Секреты не выводить на экран.
- Getcha (pm2 `empathy-bridge`) и другие проекты на сервере не трогать: `pm2 restart` только по имени
  `personal-assistant-bot`.
- Поменял промпт или инструменты — прогнать `evals/compare_models.py` на сервере (через пользователя).
